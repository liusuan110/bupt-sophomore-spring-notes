# 概率论与随机过程

北京邮电大学电子工程学院大二下《概率论与随机过程》课程资料归档。

这里主要保存课程笔记、三学分课件、往年题、公式整理、中期论文和配套图表代码。复习时建议先用公式速查建立知识地图，再按真题训练常见题型。

## 资料分类

- `概率论笔记.pdf`：课程笔记主文件。
- `三学分课件/`：概率论、随机变量、数字特征、极限定理、随机过程、泊松过程、维纳过程、平稳过程和马尔可夫链等课件。
- `往年题/`：历年试卷、答案和图片版资料。
- `figures/`：中期论文相关图像、脚本和导出图表。
- `中期论文/`：Typst 源文件和论文写作相关材料。
- `概率论与数理统计公式 - xqmmcqs's blog.pdf`：公式参考资料。

## 复习建议

1. 前半部分按“概率公式 -> 一维随机变量 -> 二维随机变量 -> 数字特征 -> 极限定理”复习。
2. 后半部分按“随机过程概念 -> 独立增量过程 -> 泊松/维纳过程 -> 平稳过程 -> 马尔可夫链”复习。
3. 真题优先训练条件概率、全概率与贝叶斯、联合密度、边缘/条件分布、期望方差、中心极限定理和马尔可夫链转移概率。
4. 最后阶段用公式速查查漏补缺，不建议重新铺开教材式学习。
