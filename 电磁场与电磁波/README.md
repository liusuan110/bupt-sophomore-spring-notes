# 电磁场与电磁波

北京邮电大学电子工程学院大二下《电磁场与电磁波》课程资料归档。

这里主要保存课程课件、课堂笔记、作业解答、复习资料、往年期末题和开放题材料。复习时建议先看章节课件和笔记建立框架，再用作业解答和往年题检查计算细节。

## 资料分类

- 章节课件：`1 矢量分析`、`2 静电场`、`3 静磁场`、`第5章 时变电磁场`、`第6章 平面波`、`7 波的反射与折射`、`8 波导和传输线`、`9 电磁场的辐射` 等。
- 课堂笔记：`电磁波 第六章 笔记`、`电磁波 第七章 笔记`、`电磁波 第八章笔记`、`电磁波 第九章笔记` 以及若干手写笔记 PDF。
- 作业与习题：第一章、第二章、第三章作业解答，以及习题课资料。
- 期末资料：`电磁场与电磁波期末题/` 中保存历年期末试卷。
- 开放题：`开放题/` 中保存开放题 Typst 源文件和导出 PDF。

## 复习建议

1. 前四章先抓公式来源和边界条件：矢量分析、静电场、恒定电场、静磁场。
2. 第五章以后按“麦克斯韦方程组 -> 平面波 -> 反射折射 -> 波导 -> 辐射”串起来。
3. 做往年题时重点检查单位、方向、边界条件、相量约定和结果量纲。
4. 开放题材料可以作为课程论文写作和 Typst 排版参考。
