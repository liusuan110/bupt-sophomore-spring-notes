# 数字电路与逻辑设计

北京邮电大学电子工程学院大二下《数字电路与逻辑设计》课程资料归档。

这里主要保存数电课件、课堂笔记、作业资料和往年试题。复习时建议先按章节建立知识框架，再用往年题训练逻辑函数化简、组合逻辑设计、时序逻辑分析与设计、中规模器件应用等高频题型。

## 资料分类

- 章节课件：第一章到第九章相关 PDF。
- 课程笔记：`2.数电笔记.pdf` 等整理资料。
- 作业资料：`作业数电.pdf`。
- 往年题：2011、2015、2017、2023 等试卷资料。

## 复习建议

1. 期中前重点关注数制码制、逻辑代数、卡诺图化简、门电路外特性和组合逻辑设计。
2. 期末重点关注触发器、时序逻辑分析与设计、计数器、移位寄存器、存储器、PLD、DAC/ADC。
3. 做题时把“状态表 -> 状态图 -> 激励方程 -> 输出方程 -> 逻辑图”的链条写完整。
4. 往年题适合最后阶段查漏补缺，尤其注意中规模器件和时序题的规范步骤。
